# 順勢策略分析工具

策略回測與研究工具(台股、美股、加密貨幣),在**自己的 Windows 電腦本機執行**。它是研究與學習用途,不預測未來,也不提供買賣建議。

## 功能
- 自選清單:每個標的的扣成本報酬、淨 PF、最大回撤、樣本外驗證;展開看 K 線、指標、進出場明細
- 標的分析:權益曲線 vs 買進持有、回撤、成本、樣本內/樣本外對照
- 最佳策略 / 策略實驗室(深度分析):跑完所有策略,**只用樣本內(IS)排名**,再對前幾名做一次樣本外(OOS)驗證
- 市場環境:各標的目前的 ADX 市場性格(只描述,不影響排名或訊號);ADX 為教科書 Wilder(14),介面標示 `ADX (Wilder, 14)`
- 回測已計入成本:加密約 0.14%、台股約 0.47%(ETF 約 0.27%)、美股約 0.04%(皆為來回)

## 樣本外(OOS)展示分級
依樣本外交易筆數:**少於 20 筆=樣本不足;20～49 筆=初步觀察;50 筆以上=可進一步評估。**
這只是樣本量分級,**不是統計顯著性判定,也不代表策略有效或能獲利**;畫面一律同時顯示實際的 OOS 淨 PF、報酬、最大回撤與筆數。
舊版的「OOS 至少 5 筆且 PF>1」只是程式內部的技術條件,畫面上只以「舊版技術門檻」小字標示,不是研究可信度。

## 分析進度與 Research Core(策略實驗室)
- **進度只來自後端真實事件。** 彈窗、最佳策略頁、策略實驗室送出分析時都會帶一個隨機的 `job` 代號;後端在既有流程的開始/完成處記錄事件(行情資料、指標計算、策略回測、訊號判斷、樣本外驗證、風險與成本),前端只在請求進行中輪詢 `/api/job_events`(這個端點不做任何運算)。
- 後端知道「第 i 個 / 共 n 個」(例如 166 個策略)才顯示 `i / n`;不知道就顯示「處理中」,**不編造百分比**。分析中可按「取消」,後端會在下一個策略開始前停止,不會留下半套結果;關閉彈窗、關閉分頁也會取消。
- **策略實驗室**有一個球形網絡面板(整個網站只有這一個):路線與光點只在真實事件發生時亮起,點擊節點可看該階段的實際結果(耗時、筆數、樣本內/樣本外表格)。沒有分析時是靜態畫面;「裝飾旋轉」預設關閉;手機、背景分頁、`prefers-reduced-motion` 時不跑動畫迴圈。
- 加不加 `job` 不會改變任何分析結果(自動化測試比對);分析請求只多一個 `job` 參數,不會為了進度重跑策略或重新下載 K 線。
- 「重播」錄製紀錄只存在於獨立原型 `static/prototype/research-core-v2.html`(測試與展示用),不在正式網站。設計與證據對照見 `docs/research_core_events.md`。

## 多週期技術狀態與資料品質(市場環境頁)
- 「市場環境」頁可查看任一標的的**週線、日線,以及資料來源實際支援的 4H、1H**:每個週期各自取資料、各自檢查資料品質,顯示 EMA 排列、收盤相對 EMA、ADX 與 ±DI、ATR%。這只是已收盤 K 棒上技術指標目前位置的**描述,不是價格預測**。
- 沒有資料或不支援的週期會明說(台股/美股沒有原生 4H),**不會用其他週期代替**;最新一根未收盤的 K 棒一律排除。
- 資料品質狀態:資料正常 / 資料不足 / 資料過期 / K 棒尚未收盤(已排除) / 合成時間週期不完整 / 時間戳異常或重複 / 資料取得失敗。週末與假日休市不算故障(美股假日用規則算;台股假日用大盤基準日線當證據)。
- **資料過期或異常時,卡片、標的分析、導覽列不會把舊資料顯示成最新交易訊號**(顯示「⚠ 資料過期，不顯示最新訊號」)。
- 已快取的資料會標示「使用快取(N 分鐘前取得)」。設計與判斷規則見 `docs/c1_data_quality_mtf.md`。

## 市場環境 × 策略歷史績效(C2,市場環境頁)
- 把策略的每一筆歷史交易,歸到**進場決策當下已收盤**的市場環境(上升趨勢/下降趨勢/盤整/趨勢轉換中;和卡片上的市場性格同一套 ADX (Wilder, 14) + ±DI 規則,只用當時及過去的 K 棒,沒有前視),看各環境的筆數、扣成本報酬、淨 PF、勝率、最大回撤、平均每筆,樣本內與樣本外分開。筆數 < 20 標「樣本不足」。
- 環境可選標的自身或大盤(加密 BTC、台股加權指數、美股 S&P 500/Nasdaq;只用同市場同週期,不使用更晚的大盤資料)。
- 濾網對照:「假設只在特定環境允許新進場」vs 原始策略(出場、成本、資金、期間相同)。樣本外預設不揭露,避免用樣本外反覆挑條件。這是歷史研究,**不會**套用到實盤機器人,也不是建議。設計見 `docs/c2_market_regime_study.md`;技術債見 `docs/tech_debt.md`。

## 在本機執行
```
pip install -r requirements.txt
python app.py
```
然後打開 http://localhost:5000 (只綁本機,沒有對外開放)。

## iPhone / PWA
網站有 PWA manifest 與主畫面圖示,**沒有 Service Worker**(不做離線快取)。iPhone Safari 能把頁面「加入主畫面」成為全螢幕入口;但目前網站只在本機執行,iPhone 要連線仍需另外的安全連線方式(尚未設定,見 docs)。自選清單存在各瀏覽器自己的 localStorage,不同裝置不會同步,可用「匯出/匯入」搬移。
