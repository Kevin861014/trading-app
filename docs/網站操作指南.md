# 順勢策略分析網站 操作指南(給完全不懂技術分析的人)

> **這份指南怎麼來的:** 2026-11-06 閱讀網站目前的前端程式(`static/index.html`、`static/js/*.js`)、後端路由(`app.py`)與已完成的研究文件後寫成,只描述**目前真的存在**的畫面。沒有用瀏覽器逐頁點過,所以標有「(依程式碼判斷)」的地方是我讀程式得到的結論,不是畫面實測。
> **先講最重要的三件事:**
> 1. **這個網站不會下單,也不連你的幣安帳戶。** 它只做「用過去的價格資料,假裝照某個策略操作,看結果如何」。畫面上所有績效都是**假設的歷史模擬**,不是真的成交。
> 2. **你的機器人實盤成績、組合模擬、歷史研究(D1~D4)都不在網站裡。** 它們是另外跑出來的報告檔(放在 `docs/` 資料夾),網站上沒有任何按鈕或頁面。第 6 節會把它們一一分開講。
> 3. **K 線圖上的「買」「賣」小箭頭,是回測模擬出來的進出場點,不是即時訊號,也不是你的真實成交。** 第 3 節專門講。

## 2 先看一次的白話名詞

| 名詞 | 白話意思 |
|---|---|
| **回測** | 拿過去的價格,假裝當時照這個策略操作,算出會賺或賠多少。它回答「這套規則過去表現如何」,**不是預測未來**。 |
| **K 線 / K 棒** | 一根棒子代表一段時間的行情(開盤、最高、最低、收盤)。 |
| **時框** | 一根 K 棒代表多久:**日線**=1 天、**4H**=4 小時、**1H**=1 小時。 |
| **已收盤 K 棒** | 這段時間已經結束的 K 棒。網站只用已收盤的,最新那根還在走的會被丟掉。 |
| **策略** | 一套固定的進出場規則,例如「均線向上就買、跌破就賣」。網站內有約 184 種。 |
| **扣成本** | 回測已扣除手續費與滑價(台股另含賣出證交稅)。頁尾寫的來回成本:加密約 0.14%、台股約 0.47%(ETF 約 0.27%)、美股約 0.04%。 |
| **扣成本報酬** | 這段期間策略總共賺或賠幾 %(已扣成本)。 |
| **淨 PF(獲利因子)** | 「總賺的錢 ÷ 總賠的錢」。**大於 1 = 這段歷史賺比賠多**;1.5 就是每賠 1 元賺 1.5 元。交易筆數很少時這個數字很不可靠。 |
| **最大回撤** | 資金從最高點最多跌掉幾 %。越小越能睡得著覺。 |
| **勝率** | 賺錢的交易占幾 %。順勢策略勝率低(約 25~40%)很正常,靠賺的比賠的大撐起來。 |
| **年化** | 把總報酬換成「每年」的速度。期間很短時會被誇大,別太當真。 |
| **買進持有** | 對照組:同一段時間什麼都不做、一直抱著這檔(**未扣成本**)。策略要比它好才有意義。 |
| **樣本內 IS / 樣本外 OOS** | 把歷史切成前 70% 與後 30%。前段(IS)用來挑策略;後段(OOS)是挑策略時**沒看過**的資料,用來檢查是不是只是湊巧。 |
| **樣本外「分級」** | 只看樣本外**交易筆數**:少於 20 筆=樣本不足;20~49=初步觀察;50 以上=可進一步評估。**這只是樣本量,不代表策略有效或會賺錢。** |
| **ADX / 市場性格** | 一個判斷「有沒有趨勢」的指標。≥25 趨勢(再依 +DI/−DI 分上升/下降)、<20 盤整、20~25 趨勢轉換中。只是描述現在,**不會擋掉任何訊號,也不影響排名**。 |
| **EMA20 / EMA50** | 兩條平均價格線(短期、長期)。短的在長的上面=偏多。 |
| **策略類型** | 順勢(跟著趨勢)、均值回歸(漲多回頭、跌多反彈)、突破三類。順勢/突破適合有趨勢的行情;均值回歸適合盤整。 |

**顏色約定(注意:跟台股習慣相反):**
- **綠色=上漲/正數/偏多**,**紅色=下跌/負數/偏空**(K 棒綠漲紅跌)。
- 橘黃色=警告(資料過期、訊號過期、策略類型不合行情)。灰色=中性或沒資料。

**結果標籤(畫面上的小色塊,務必分清楚):**

| 標籤 | 意思 |
|---|---|
| 歷史回測 | 整段歷史的模擬結果 |
| 樣本外測試 | 挑策略時沒用到的後段資料的結果 |
| 即時技術訊號 | 策略「現在」的狀態(不是預測、不是買賣建議) |
| 技術指標描述 / 規則式,不是 AI | 把已算好的數字用固定規則描述成文字 |
| 紙上交易(灰色) | 尚未提供 |

## 3 K 線圖的「買」「賣」標記到底是什麼

### 3.1 一句話
**它是「回測模擬器假裝成交」的位置,不是策略「訊號」本身,也不是你或機器人的真實成交。**

### 3.2 逐項回答你的問題

**① 是策略訊號還是模擬成交?→ 模擬成交的位置。**
策略先在某根 K 棒收盤時判斷「條件成立」(這是訊號)。模擬器假設**下一根 K 棒開盤**才成交(並扣手續費、滑價)。圖上的 **▲買** 畫在「模擬成交的那一根」,也就是**訊號棒的下一根**。
- 進場價 = 那根 K 棒的**開盤價**(不是收盤價,也不是箭頭畫的位置)。下方「最近進出場」列表和「進出場明細」顯示的價格才是模擬成交價。
- **▼賣** 畫在模擬出場的那根:如果是策略的賣出條件,就是訊號棒的下一根開盤價出場;如果是停損或停利被打到,就是被打到的那一根(用停損價成交;若跳空越過則用開盤價)。
- 買賣價位都**已含成本**(列表上的報酬是扣完成本的)。

**② 是否只使用已收盤 K 棒?→ 是。**
程式在抓資料時會把「還在走的最後一根」丟掉(加密貨幣與 Yahoo 的日內/日線都一樣),策略與回測、圖上的標記都只看已經結束的 K 棒。畫面上的「資料時間」會寫「最後已收盤 K 棒 … UTC」。

**③ 歷史訊號會不會重新計算後消失?→ 在「相同資料、相同設定」下不會因為新 K 棒出現而消失,但在下列情況標記可能改變或消失:**

| 情況 | 為什麼 |
|---|---|
| **換了期間**(例如 1 年改 2 年) | 回測是「空手開始、一次只持一筆」。起點不同,暖機資料與持倉狀態就不同,同一個日期的買賣點可能多一個或少一個。 |
| **換了策略或時框** | 當然不同。 |
| **程式或規則被更新** | 例如 2026-11-05 修了成本、停損時序、未收盤棒的問題,舊結果就不同了;2026-10-29 以前網站的「4H」其實是用 1H 算的。 |
| **股票的價格被資料商調整** | 台股/美股用 Yahoo(含除權息調整),配息或分割後整段歷史價格會被重新調整,舊標記可能移位。加密貨幣用幣安原始 K 棒,幾乎不會被改。 |
| **最新一根** | 「最新的買進/賣出」要等**下一根 K 棒收盤**後才會出現(因為成交在訊號的下一根)。所以你看到「▲ 買進訊號!」時,策略條件其實是**上一根**就成立了。網站**不是**下單提醒工具。(依程式碼判斷) |

另外:策略本身只用「當下以前」的資料(沒有偷看未來),開發紀錄中有掃描過全部策略,發現的 1 個問題已修正;但這是程式保證,不代表標記對未來有預測力。

### 3.3 圖上其他東西
- **綠線 EMA20、紅虛線 EMA50:** 兩條均線,看趨勢方向用。
- **下方小圖:** EMA差距(綠柱=EMA20 在 EMA50 之上)、KD、RSI(>70 標超買、<30 標超賣)、成交量。**這幾個小圖是前端用收盤價另外算的「看圖輔助」,不是策略實際用的條件**,不要拿來對照買賣點。(依程式碼判斷)
- 把滑鼠移到 K 棒(手機是點一下)會顯示該根的開高低收、指標、以及該根有沒有買/賣標記。
- 圖上沒有任何「你的真實買賣」。

## 4 每個頁面、每個區塊怎麼用

> 每個區塊都用同一種寫法:**位置 → 在做什麼 → 要選/輸入什麼 → 按下去會怎樣 → 結果怎麼看 → 什麼時候用、能不能忽略**。

### 4.0 所有頁面共通的小事
- **ⓘ 說明:** 很多數字旁有 ⓘ。電腦把滑鼠移上去、手機點一下(按鈕類改長按)會跳出白話說明。
- **進度條(最佳策略、實驗室、多週期、環境績效):** 顯示後端真的做到哪個階段(行情資料→指標計算→策略回測→訊號判斷→樣本外驗證→風險與成本)。**可按「取消」**,後端確認停止後不會產生半套結果。關掉彈窗也會取消。
- **資料品質徽章:** 資料旁的小標籤,常見有:✓ 資料正常、ℹ K 棒尚未收盤(已排除)、⚠ 資料不足、⚠ 資料過期、⚠ 時間戳異常、⚠ 資料取得失敗、「未檢查」。**出現 ⚠ 時,訊號與排名只代表那份舊資料,不代表現在。**
- 同一時間短時間內重複查同一檔,會用 1 小時內的**快取**(記憶體,關掉網站就清空),所以數字會「剛好沒變」;這是正常的。

### 4.1 自選清單(主頁)

**位置:** 第一個分頁。上方是「加入列」,中間是說明橫幅,下面是一張張卡片。

#### 4.1.1 加入列(搜尋框 + 策略下拉 + 「＋ 加入」)
- **在做什麼:** 新增要關注的標的。
- **要輸入什麼:** 在搜尋框打名稱或代號(例如 `台積電`、`AAPL`、`BTC`)。可從下拉選一個,或直接輸入代號後按 Enter。4 位數字會自動補成台股(`2330` → `2330.TW`)。旁邊的下拉是**新卡片要用的策略**(預設第一個「六條線」)。
- **按下去會怎樣:** 先在內建清單找,找不到就去網路驗證代號是否存在(錯了會跳出提示);成功就新增一張卡片並立刻載入。
- **搜尋時的「推薦策略」:** 選到內建清單裡的標的,搜尋列下方會出現「推薦策略」標籤(第一個有 ⭐)。**點標籤只是把上面那個策略下拉改掉**,按「＋ 加入」才會用。這些推薦是寫死的經驗清單,不是系統算出來的。
- **能不能忽略:** 不能,這是加入標的的地方。

#### 4.1.2 市場分頁(📋全部 / ₿加密 / 📈台股 / 美股 / 🥇貴金屬)
- **在做什麼:** 只是篩選卡片顯示哪個市場(旁邊的小數字是張數)。不影響任何數字。

#### 4.1.3 熱門列(📈台股 / 美股 / ₿加密 / 🥇貴金屬)
- **在做什麼:** 快速加入熱門標的。每個市場最多列前 20 個(內建台股有 77 檔,只列前 20,其他請用搜尋;美股 14、加密 12、貴金屬 2 都列得完)。
- **按下去會怎樣:** 點一個名稱就直接新增卡片(已在清單裡會提示)。**用的是上方加入列當下選的策略**,不是該標的的推薦策略。

#### 4.1.4 「這個工具是做什麼的?」橫幅
- 一次性說明。按「我知道了,開始使用 →」後會記住,不再出現。**內容可以只讀一次**,重點:扣成本後的數字、樣本外只是樣本量分級、即時技術訊號只是目前狀態。

#### 4.1.5 工具列「全部展開 / 全部收合」
- 卡片預設是精簡的;展開後才有 K 線圖與詳細指標。這個按鈕一次展開/收合目前顯示的所有卡片。展開狀態會記在瀏覽器。

#### 4.1.6 一張卡片(最重要)

**由上到下:**

1. **標題列:** 名稱 + 市場徽章;下面是「代號 · 策略 · 時框」與一個**市場性格徽章**(🔼上升趨勢 / 🔽下降趨勢 / ↔️盤整 / ⚪未分類,附 ADX 數字);再下面一行「資料時間」+ 資料品質徽章。
2. **右上按鈕:**
   - **🔍 最佳策略:** 跳出視窗,對這檔把所有策略排名(同 4.3,只是在彈窗裡)。
   - **🔬 深度分析:** 跳出視窗,更長資料、更嚴門檻(同 4.4)。
   - **⛶ 放大 K 線:** 開大圖(見 4.1.7)。
   - **↺ 重新載入:** 重新算這張卡。
   - **✕ 刪除:** 先問「確定刪除?」再刪。
3. **橘色警告(可能出現):** 「⚠ 順勢策略遇上盤整,訊號可信度打折…」。意思:你選的策略類型和現在行情的性格不合,**不是不能用,是要更小心**。
4. **訊號橫幅(大字):** 策略「現在」的狀態,右側有「即時技術訊號」標籤。可能的文字:

   | 橫幅 | 意思 |
   |---|---|
   | ▲ 買進訊號! | 最後一根已收盤 K 棒就是**模擬進場棒**(條件在前一根成立)。 |
   | ▼ 賣出訊號! | 最後一根是模擬出場棒。 |
   | ▲ 策略建議持有中 第N天 | 回測裡這個策略的「**模擬部位**」目前還在場內(進場價、浮動損益見副標)。**不是你帳戶的持倉。** |
   | ⚠ 訊號已過期 | 日線:模擬持有超過 3 天,或現價已高於進場價 3% 以上,表示「追進已晚」。(依程式碼判斷:1H/4H 因日期格式問題,這個判斷實際不會觸發。) |
   | ▼ 策略已出場 | 曾進場、現已出場。 |
   | ▲ 多頭趨勢 · 等待訊號 / ▼ 空頭趨勢 · 觀望 / — 中立 | 沒有模擬部位時,依 EMA20 與 EMA50 的差距(超過 ±0.1%)描述方向。 |
   | ⚠ 資料過期,不顯示最新訊號 | 資料太舊,故意不顯示訊號。 |
   | — 資料不足 / — 連線失敗 / — 此時框不支援 | 字面意思。 |
5. **四個重點數字(KPI):** 扣成本報酬、淨 PF、最大回撤、樣本外驗證(例如「初步觀察 · OOS 25 筆 · 淨 PF 1.2 · +3.1% · 回撤 5%」)。**這四格才是判斷依據,不是橫幅的顏色。** 數字意思見第 2 節。這些是「歷史回測」。
6. **「展開詳細 ▾」** 展開後有:
   - 年化、勝率、交易筆數(用加碼策略時會註明加碼次數)、買進持有(報酬與回撤)、累計成本。
   - 「歷史回測」說明:每筆來回成本、期間、筆數、累計成本占期初權益多少 %。
   - 「樣本外測試」表:樣本內 / 樣本外並排(各自的日期範圍、報酬、PF、回撤、勝率、筆數),下面註明「跨越邊界的交易兩邊都不算」。**「舊版技術門檻」是程式內部舊條件,不是可信度,可以忽略。**
   - 三個下拉(策略、期間、時框):**改了會存在這張卡上並重算**。期間可選 7天~5年;時框 日線/4H/1H(台股、美股不支援 4H,會標「(不支援)」)。
   - 四個指標開關(EMA差距、KD、RSI、成交量):只控制下方小圖顯示。
   - K 線圖(見第 3 節)。
   - 「最近進出場」列表:最近幾筆**模擬**交易:`▲進場價 → ▼出場價 報酬%`,附日期。
   - 「📊 標的分析」按鈕:跳到標的分析頁看同一組設定的完整版。
7. **什麼時候用/能不能忽略:** 日常只看標題列的資料時間、橫幅、四個 KPI 就夠。展開詳細、指標開關可以不碰。

#### 4.1.7 放大 K 線(⛶ 彈窗)
- 大圖版 K 線,多了「期間」與「時框」下拉可以臨時換著看(**不會存回卡片**,也不會換策略;策略沿用卡片的),以及指標開關。按 ✕ 或 Esc 關閉。

#### 4.1.8 ☰ 股票列表(右側抽屜「📋 我的股票」)
- **在做什麼:** 依市場分組,列出清單內每檔的小圓點與狀態文字(▲買進!、▲持有中、▼賣出!、⚠已過期、⚠資料過期、▼已出場、多頭等待、▼空頭、— 中立)。點一檔會捲動到它的卡片。
- **注意:** 還沒載入完整卡片的標的,用的是較輕量的訊號(只抓最近約 300 天資料),跟卡片上的結果**可能略有不同**。以卡片為準。
- **能不能忽略:** 可以。它只是目錄。

### 4.2 標的分析

**位置:** 第二個分頁。把一檔標的完整攤開。

- **在做什麼:** 單一標的 + 單一策略的完整回測報告。
- **要選什麼:** 標的(清單內的)**或**直接輸入代號;策略;期間;時框。選清單內的標的時,會自動帶入它卡片上的設定。**這裡怎麼改都不會動到自選清單**,除非按右邊的「套用到自選清單」(會先確認;標的要已在清單裡)。
- **按「分析」會怎樣:** 重新取資料並回測,大約幾秒。
- **結果由上到下:**
  1. **抬頭:** 名稱、代號、策略、時框、期間;資料時間 + 資料品質徽章 + 共幾根已收盤 K 棒;「即時技術訊號」(同卡片橫幅)與「市場性格」。
  2. **研究摘要(按鈕「產生／更新研究摘要」):** 用固定規則把已算好的數字整理成中文說明,每一句都能展開「判斷依據」看引用了哪個欄位。**不是 AI、不是預測、不是買賣建議。** 它會另外去取多週期與市場環境資料,所以比較慢。可以忽略。
  3. **歷史回測面板(左):** 扣成本報酬、淨 PF、最大回撤、勝率、交易筆數、年化、買進持有報酬/回撤;下方「每筆來回成本…、此期間共 N 筆交易,累計成本約為期初權益的 x%」。
  4. **樣本內/樣本外面板(右):** 同卡片的表,日期範圍清楚標出。
  5. **權益曲線與回撤:** 綠線=策略資金變化(已扣成本,以期間起點為 0%);灰虛線=買進持有(未扣成本);下方紅柱=策略每個時點離高點跌了多少。**看策略線有沒有高過灰線、紅柱深不深。** 滑鼠移上去看同一時間的數字。
  6. **K 線與進出場:** 同第 3 節。標題旁註明「▲▼ 為歷史回測的進出場點」。
  7. **進出場明細(已扣成本):** **只列最近 10 筆**(畫面上的「交易筆數」是整段期間的總數,會比這裡多)。
  8. 最底下一行:「未來紙上交易:尚未提供」。
- **什麼時候用:** 在卡片上覺得有興趣時,想看「這策略到底比單純持有好多少、過程跌多深」。想看權益曲線只有這裡有。**一般使用者的第二站。**

### 4.3 最佳策略

**位置:** 第三個分頁(手機底部寫「排名」)。

- **在做什麼:** 把適合該市場的策略全部跑一遍,**只用前 70% 歷史(樣本內)排名**,取前 8 名,再用後 30%(樣本外)各驗證一次。樣本外只用來標註,**不影響排名**。排名已扣成本。
- **篩選門檻:** 樣本內淨 PF 要大於 1、回撤小於 50%、交易筆數夠(加密至少 10 筆、其他至少 5 筆);沒過的不會出現。「綜合分數」只看樣本內,約等於「PF × 交易筆數的對數 × 報酬加成 ÷ (1+回撤)」。
- **要選什麼:** 標的(清單內的)或輸入代號、期間、時框、是否勾「樣本外驗證」(預設勾,建議不要取消)。
- **按「開始分析」會怎樣:** 通常 20~40 秒,有進度條與「取消」。
- **結果怎麼看:**
  - 最上方一條橫幅寫明樣本內/外各是哪段日期。
  - 表格每一列一個策略:🥇🥈🥉…名次、策略名、**樣本內(報酬、淨 PF、筆數)**、**樣本外(報酬、淨 PF、筆數、回撤)**、**全期間(僅供參考)**、**驗證分級**、操作。
  - 策略名旁的小標籤:順勢/均值回歸/突破;前面有 ✓ 代表這類策略「通常適合現在的市場性格」(只是參考,不影響排名)。
  - **操作「套用」:** 把這個策略設到該標的的卡片上(只有標的在自選清單內才有,會立刻重算);**「詳細」:** 跳到「標的分析」看完整版。
- **請這樣解讀:** 排名第一**不代表未來會賺**:從上百個策略裡挑歷史最好的,本來就容易挑到湊巧的。看**樣本外的實際 PF、報酬、回撤與筆數**,不要只看分級或名次。
- **沒有結果時:** 會寫「沒有策略在樣本內通過篩選」,可換長一點的期間。
- **什麼時候用:** 想替某一檔換策略時。**不想換就不用。**

### 4.4 策略實驗室(深度分析)

**位置:** 第四個分頁。

- **在做什麼:** 和「最佳策略」同一類排名,但資料更長(加密約 2 年、台股/美股約 5 年)、筆數門檻更嚴(加密 15 筆、其他 8 筆),所以要等 **1~2 分鐘**。同樣樣本內排名、樣本外驗證。
- **要選什麼:** 標的、時框、是否勾樣本外。**沒有「期間」選項**(固定)。
- **結果:** 與最佳策略相同的表格。多了一塊「**研究核心**」球體與階段進度:球體、路線、光點只是把後端真實進度畫出來(沒在分析時是靜態圖);點一個節點可看該階段做了什麼、花多久。**這只是進度的視覺化,對判斷沒有幫助,可以完全忽略。**

- **什麼時候用:** 最佳策略的結果很有興趣、想用更長資料再檢查一次時。**可以先忽略。**

### 4.5 市場環境

**位置:** 第五個分頁。由上到下三個區塊。進入這一頁時,最下面的表格會**自動**開始載入。

#### 4.5.1 區塊一:「多週期技術狀態與資料品質」
- **在做什麼:** 同一檔標的,並排看週線、日線、4H、1H 各自的資料品質與技術狀態,看不同時間尺度的方向有沒有一致。
- **要選什麼:** 標的(清單內)或輸入代號,按「查看多週期」。
- **按下去會怎樣:** 每個週期各自取資料、各自檢查品質,會顯示進度,並註明這次資料是「使用快取」還是「重新取得」。
- **表格欄位:**

  | 欄位 | 白話 |
  |---|---|
  | 週期 | 週線/日線/4小時/1小時 |
  | 資料品質 | 資料正常、過期、不足…;**過期的列會變淡,不列入一致性判斷** |
  | 最後已收盤 K 棒 | 資料最後到什麼時候(日內同時顯示當地時間與 UTC) |
  | 資料來源 | 幣安公開行情 或 Yahoo Finance |
  | 趨勢(ADX / ±DI) | 有沒有趨勢、往哪邊;附 ADX、+DI、−DI 數字 |
  | EMA 排列 | EMA20/50/200 的上下排列(多頭排列/空頭排列/糾結) |
  | 收盤 vs EMA | 收盤價在三條均線之上還是之下 |
  | ATR% | 平均波動幅度占價格的 %(越大越震盪) |
  | 技術偏向 | **偏多**=收盤>EMA50 且 EMA20>EMA50 且 +DI>−DI;**偏空**=反之;其餘=中性/分歧 |

  最上方一句總結:「所有可用週期都偏多/偏空(一致)」或「方向分歧」。
- **限制:** 台股、美股**沒有 4H**(資料來源只有 1H,合成的 4H 對不上交易時段),該列會寫「資料來源不支援此週期」,不會拿別的週期頂替。
- **這是描述,不是預測或建議。** 能忽略嗎:可以;想確認「大週期是不是同方向」時才用。

#### 4.5.2 區塊二:「市場環境 × 策略歷史績效」
- **在做什麼:** 把某個策略過去的**每一筆交易**,依「進場那一刻」的市場環境(上升趨勢/下降趨勢/盤整/趨勢轉換中)分類,看它在哪種環境賺、哪種環境賠。環境分類只用進場當下已收盤的資料。
- **要選什麼:** 市場(篩選標的清單)、標的、時間週期、期間(預設 2 年)、策略;按「分析環境績效」。
- **結果:**
  - 「窗口內各環境佔比」色條:這段期間各種環境各占幾 %。
  - **環境基準切換:** 「標的自身環境」或「大盤環境」(加密用 BTC、台股用加權指數、美股用 S&P 500/Nasdaq)。
  - **樣本內(IS)表**與**樣本外(OOS)表:每種環境的交易筆數(+樣本量分級)、平均每筆、合計報酬、淨 PF、勝率、最大回撤。筆數少於 20 筆的列一律當樣本不足。「本站回測」小字是同一策略在其他頁的整體數字,方便對照。
  - **濾網對照(A vs B):** A=原始策略;B=假設只在你勾選的環境才允許新進場(出場、停損、成本都不變)。按「**比較(只看樣本內)**」看樣本內;確定條件後才按「**查看樣本外(會被計數)**」。
  - **條件試驗紀錄:** 記你試過幾個條件、看過幾次樣本外。試太多次會跳警告(越試越容易挑到湊巧的)。**這份紀錄只存在這個瀏覽器,可以被繞過,只是提醒自己。**
  - 「研究摘要」按鈕:同 4.2。
- **這裡的「A / B」跟 D2/D3 研究報告的「A / B」是兩回事**(見第 5 節)。
- **這是歷史統計,不是預測,也不會套用到任何實盤。**
- **能忽略嗎:** 可以,這是進階研究。

#### 4.5.3 區塊三:清單內每檔的市場性格表
- **在做什麼:** 把自選清單每一檔「現在」的市場性格(ADX)、你選的策略類型,以及「策略類型 vs 性格」是否相符排成一張表。
- **按下去會怎樣:** 進入頁面自動載入(最多同時 3 個請求);「重新整理」按鈕強制重抓;右邊顯示最後更新時間。10 分鐘內不重抓。
- **怎麼看:** 最後一欄顯示「類型相符」或橘字警告(例如順勢策略遇上盤整)。只是提醒,不擋任何東西。
- **能忽略嗎:** 可以。想一次檢查所有卡片的策略是否「對盤」時才看。

## 6 哪些數字是真的、哪些是假設、哪些只是研究結果

| 類別 | 內容 | 在哪裡 |
|---|---|---|
| **真實的(外部事實)** | K 線(開高低收、成交量)取自幣安公開行情或 Yahoo Finance;網站已丟掉未收盤的最後一根 | 網站所有圖與資料時間 |
| **真實的(你自己的)** | 你的機器人真實成交、手續費、資金費率、入金、損益 | **只有 D1 報告**;網站完全看不到 |
| **假設的回測** | 卡片與標的分析上的所有報酬、PF、回撤、勝率、筆數、年化、權益曲線、買賣標記、進出場明細、「策略建議持有中」的模擬部位 | 網站 |
| **假設中的假設** | 「買進持有」對照(未扣成本);樣本外分級(只是樣本量) | 網站 |
| **研究結果(分析、不是預測)** | 市場環境績效、濾網對照、多週期「技術偏向」、研究摘要、策略排名 | 網站(市場環境、最佳策略、實驗室) |
| **離線研究結果** | D2 模擬重現率、情境比較;D3 各區段 A/B 比較、倖存者偏誤說明 | 報告檔 |
| **尚未存在** | 紙上交易的實際成績(D4 尚未啟動) | — |

**回測假設了什麼(務必知道):** 一次只持一筆多單(不做空;極少數策略可加碼)、每筆用固定風險比例與槓桿上限、成交在訊號後下一根開盤、扣固定比例手續費與滑價。**沒有模擬:** 拒單、斷線、流動性不足、你的真實成交差異、資金費率(網站回測不含)。

## 7 重複、尚未啟用與已知限制(直接說)

**功能重複:**
- **卡片按鈕「🔍 最佳策略」「🔬 深度分析」(彈窗)** 與 **「最佳策略」「策略實驗室」分頁**是**同一套排名**,只是一個在彈窗、一個在專頁。專頁可以任意輸入代號,不必先加進清單。
- **卡片「展開詳細」** 與 **「標的分析」**內容大幅重疊;差別是「標的分析」多了**權益曲線/回撤圖**、研究摘要與樣本內外並排表。
- **「☰ 股票列表」抽屜** 與卡片橫幅是同一件事的目錄版,但可能用較輕量的資料,數字略不同。
- **「放大 K 線」** 與 **「標的分析」的 K 線**都是同一張圖,只是放大版。

**尚未啟用 / 不存在:**
- 紙上交易:網站沒有(標籤寫「尚未提供」)。
- 實盤連線、下單、帳戶:沒有,而且網站程式裡沒有任何帳戶存取程式碼。
- 策略實驗室頁的小字「尚未提供:不同市場環境下的歷史表現」已過時,該功能在市場環境頁。

**已知限制(影響你解讀):**
1. **所有績效都是歷史模擬**,過去不代表未來;排名第一大多是挑選偏誤。
2. **訊號比實際晚一根:** 看到「買進訊號!」時,條件通常在前一根就成立;模擬進場價是這根的開盤價。網站不適合當即時下單提醒。(依程式碼判斷)
3. **1H 資料最長約 680 天:** 在卡片、標的分析、最佳策略選 3 年、5 年,1H 實際資料也只到約 680 天(程式上限);策略實驗室的 1H 與所有 4H 沒有這個上限。(依程式碼判斷)
4. **台股、美股不支援 4H**(會直接標示不支援);日線與 1H 可用。
5. **進出場明細只列最近 10 筆**,筆數以 KPI 為準。
6. **歷史上網站曾把「4H」用 1H 算(2026-06-09~10-29)**,已修正。那段期間存下的截圖、印象不要再引用。
7. **加密貨幣行情失敗時會直接報錯**,不會偷偷改用別的來源(這是 11-06 修的);此時上方標籤會寫「幣安連線失敗」,需檢查網路後重啟網站。
8. **幣安官方資料自己有 74 根 4H 棒的 1H 與 4H 對不上**(0.026%),集中在 2019、2020 與 2022-07-16、2023-11-10、2024-10-28 等幾個時間點;網站預設 2 年的 4H 回測只會碰到 2024-10-28 20:00 那一根;期間更長或策略實驗室(含暖機約 3 年)還會碰到 2023-11-10 的 2 根。影響很小,但比較結果時要知道(見 `docs/data_audit_20261106/`)。
9. **「訊號已過期」在 1H/4H 實際不會顯示**(日期格式問題,依程式碼判斷),只有日線有用。
10. **各種數字不同的常見原因:** 期間不同、時框不同、卡片與抽屜用的資料窗口不同、快取、程式更新。**不同頁面的數字要在同一檔、同策略、同期間、同時框下才能比。**
11. **條件試驗紀錄不可靠**(只在你的瀏覽器,可被繞過)。
12. **自選清單只存在這個瀏覽器**,請定期用「匯出」備份。
13. **這個工具不是投資建議。**

## 8 第一次打開網站:實際操作流程

**目標:花 15 分鐘,弄懂一檔標的目前的策略狀態與歷史成績,而且不被數字騙。**

1. **確認網站活著:** 開 `http://localhost:5000`。看右上角的資料來源小字:加密貨幣要是綠色「加密4H（ccxt）」;若寫「幣安連線失敗」,先處理網路再重啟。
2. **讀一次橫幅:** 在「自選清單」讀「這個工具是做什麼的?」,按「我知道了,開始使用 →」。
3. **看現成的卡片:** 預設有 7 張(台積電、鴻海、長榮、0050、PAXG、SOL、ETH)。先不要展開,只看每張:
   - 「資料時間」是不是剛剛(資料過期要小心);
   - 大字橫幅(買進訊號/持有中/空頭…);
   - 四格:**扣成本報酬、淨 PF、最大回撤、樣本外驗證**。
4. **用三個問題檢查一張卡:**
   - ① 報酬有沒有比「買進持有」好?(按「展開詳細 ▾」看「買進持有」。)
   - ② 最大回撤你受得了嗎?(回撤 20% = 100 萬會暫時變 80 萬。)
   - ③ 樣本外筆數夠嗎?(少於 20 筆=別當真。)
5. **加入你想看的標的:** 在搜尋框打名稱 → 點下拉選項 → (可點推薦策略標籤) → 「＋ 加入」。新卡片會自動載入。
6. **想換策略時:** 在那張卡按「🔍 最佳策略」(或到「最佳策略」頁)。等 20~40 秒,看表格**重點看「樣本外」那幾欄**與驗證分級;喜歡的按「套用」。**記得:排名第一不代表會賺。**
7. **想看完整報告:** 點卡片的「📊 標的分析」,看**權益曲線(綠線有沒有高過灰線)**與**回撤(紅柱深不深)**,以及模擬進出場明細。
8. **想檢查大方向:** 「市場環境」頁 → 區塊一「查看多週期」,看大小週期是不是同方向。其他區塊先跳過。
9. **之後的日常(1 分鐘):** 打開自選清單 → 看「資料時間」→ 看橫幅變化 → 有興趣才展開。**不要把橫幅當下單訊號。**
10. **最後:** 匯出一份清單備份(⬇ 匯出)。

**絕對不要做的事:** 把網站的買進價、報酬當成實盤成績;因為排名第一就直接換策略;對樣本不足(少於 20 筆)的結果下結論;拿 K 線下方 KD/RSI 小圖去對照買賣點。

## 9 常見疑問

- **「為什麼同一檔在不同頁數字不一樣?」** 期間、時框、策略或資料窗口不同;看第 7 節第 10 點。
- **「圖上的買點價格跟列表的進場價不同?」** 正常:箭頭畫在模擬成交那根 K 棒,實際模擬成交價是那根的**開盤價**(再扣滑價成本)。
- **「畫面一直轉圈或寫連線失敗?」** 確認 `python app.py` 還在執行;加密貨幣另看右上資料來源標籤。
- **「資料不足」?** 這個標的在這個時框的歷史不夠長(新上市幣、1H 太短);改日線或較短期間,或確認代號。
- **「我的機器人實盤賺還是賠?」** 不在網站裡。看 `docs/d1_live_research.md`。
- **「D4 現在在跑嗎?」** 沒有。沒有常駐、沒有排程。
- **「研究核心那顆球是什麼?」** 實驗室分析進度的動畫,可忽略。
- **手機:** 底部分頁切換;ⓘ 說明用點一下;旋轉螢幕會自動重畫圖,不會重新抓資料。
