## 4. 桌面版(A)工作內容
沿用 v1 設計,以下是定案摘要:

**資訊架構**:單頁多視圖(網址 hash 切換,不用框架):自選清單(預設)/ 標的分析 / 最佳策略 / 策略實驗室(含深度分析)/ 市場環境。桌面頂部分段導覽;說明列收合成「?」。

**卡片**:預設顯示 名稱·市場 → **資料時間(含時區)** → 策略·時框·期間 → **即時技術訊號** → **市場環境** → **資料狀態** → 3 個 KPI(**扣成本報酬、淨 PF、最大回撤**)→ **樣本外驗證**徽章。展開才顯示勝率、筆數、年化、成本、K 線與指標、進出場紀錄、權益/回撤曲線。保留自選清單、匯入匯出、K 線與指標、既有所有按鈕(次要動作收進「⋯」)。

**驗證狀態四種**(固定配色):**展示分級只看 OOS 筆數**:<20 筆=樣本不足 / 20～49 筆=初步觀察 / ≥50 筆=可進一步評估(只是樣本量分級,不是統計顯著性,不代表有效或會獲利)/ 尚未驗證;並一律顯示實際 OOS 淨 PF、報酬、回撤與筆數。舊的「≥5 筆且 PF>1」只以「舊版技術門檻(非可信度)」小字標示。禁用「保證獲利」「推薦買入」。

**比較表**(桌面):策略、時框、IS、OOS、全期間(灰字,僅供參考)、淨 PF、最大回撤、筆數、驗證狀態;可排序、可展開看曲線。

**回測視覺化**:權益、回撤、買進持有對照、手續費與滑價、期間與筆數;缺資料標「未提供」。`/api/analyze` **只新增欄位**(降取樣),不改演算法。

**C1 資料品質 + 多週期**、**C2 市場環境 + 策略實驗室**、**C3 規則式分析說明**:內容同 v1,差別是——**實驗室的排名在本機完整可用**(不再有 Render 限制),但加「單一重運算鎖」,避免同時跑多個排名拖慢電腦(這台電腦同時在跑機器人,見第 9 節)。

**資料品質狀態機**:正常 / 資料不足 / K 棒尚未收盤 / 資料過期 / 時間週期不一致 / 合成 K 棒不完整 / 資料取得失敗。異常時**不把舊訊號當最新**;股票沒有假日曆,過期判斷只能保守。時區標示:加密 UTC、台股 Asia/Taipei、美股 America/New_York。

## 6. 區域網路存取方案(C:同一個 Wi-Fi,iPhone → Windows 電腦)

**本階段不動手,只提方案。需你批准後才實作;防火牆與網路設定一律由你自己操作。**

### 6.1 現況與目標
- 現在:Flask 只綁 `127.0.0.1:5000`(安全)。
- 目標:在**你明確要求時**,讓同網段的 iPhone 連到 `http://192.168.33.148:5000`(位址會隨 DHCP 變動)。**預設仍然只綁本機**,LAN 模式是另開的、需要手動啟動的選項。

### 6.2 方案:獨立的「區網啟動器」(新檔案,不改現有 `python app.py` 行為)
| 控制 | 內容 |
|---|---|
| **獨立入口** | 新增 `serve_lan.py`(與可選的 `start_lan.bat`)。平常 `python app.py` 不變、只綁本機。LAN 模式**每次手動啟動、關視窗就停止**,不註冊服務、不開機自啟 |
| **不用 Flask 開發伺服器** | LAN 模式改用 **waitress**(純 Python、支援 Windows)。**這是唯一的新依賴**,免費(開源),僅 LAN 模式使用;預設流程不需要。強制 `debug=False` |
| **只綁一個位址** | 綁定**偵測到的私有網段 IPv4**(例如 `192.168.33.148`),**不綁 `0.0.0.0`**,避免日後多出的 VPN/虛擬網卡也被暴露 |
| **來源限制** | 只接受**同一個 /24 私有網段**的用戶端 IP;其他一律 403 |
| **Host 標頭白名單** | 只接受該私有 IP 作為 Host,擋 DNS rebinding |
| **存取權杖** | 每次啟動產生隨機權杖(存在使用者資料夾,**不在 repo、不在機器人資料夾**),啟動時在終端機印出一次含權杖的網址;第一次造訪設定 `HttpOnly` + `SameSite=Strict` cookie,之後免帶。無權杖 → 403。**誠實限制**:HTTP 下權杖是明文,同 Wi-Fi 的人能監聽,所以它只擋「隨手連進來」,**不是強加密**;要真正加密與防監聽需要 HTTPS(D) |
| **同源 CORS 與安全標頭** | LAN 模式不載入全開 CORS;加 `X-Content-Type-Options`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`、限制來源的 CSP(圖表函式庫改自帶後,可限制成只有自己 + 必要來源) |
| **輸入白名單** | `symbol`(長度與字元集)、`strategy`(必須在策略庫)、`timeframe`、`period` 嚴格驗證,不合法回 400 |
| **重運算鎖與降優先權** | 同一時間只允許一個「排名/深度分析」;LAN 服務行程設為**低於正常**優先權(Python 標準庫 `ctypes` 即可),避免拖慢同一台電腦上的機器人 |
| **啟動防呆** | 啟動時檢查:工作目錄/靜態根目錄**不得**包含 `config.portfolio*.json`、`secret_keys.json`、`*state*.json`、`*.log`(機器人檔案),發現就**拒絕啟動**;確認沒有載入任何金鑰環境變數 |
| **日誌** | 不記錄權杖與 cookie |

### 6.3 Windows 防火牆與網路(**你自己做,我不碰**)
- 現況:網路類型 **Public**、入站預設不放行 → 區網連線會被擋,這是正確的預設。
- Windows 在 Python 第一次對外監聽時會跳出提示。**請只允許「私人網路」**,不要勾「公用」。
- 要讓 LAN 可用,通常需要你把這個網路改成「私人」(這是系統層級決定)**或**自己建立一條規則:本機連接埠 5000、遠端位址限制為本機子網路(`LocalSubnet`)、僅限私人設定檔。**我不會替你改。** 實作時我會提供可直接貼上的指令與「如何復原」,由你決定。
- 路由器:**不要做連接埠轉發/UPnP**,這個方案完全不需要。我也無法從這裡驗證你的路由器對外是否安全,這需要你自己確認。
- 若 iPhone 連的是**訪客 Wi-Fi**或路由器開了 AP 隔離,連不到是正常的(裝置被刻意隔離)。

### 6.4 驗證方式(實作時)
單元測試:無權杖 403、錯誤 Host 400、非同網段 IP 403、不合法輸入 400、機器人檔案防呆會拒絕啟動、debug 強制關閉。實測:電腦自己用 LAN IP 連線;**iPhone 實機連線由你執行並回報**。我**不會**嘗試從外部探測或修改你的網路。

## 8. 與機器人的隔離邊界(硬性要求)
1. 手機端**只拿得到**靜態檔案與公開行情分析 JSON;**接觸不到**幣安金鑰、機器人設定檔、狀態檔、日誌。
2. 網站程式與機器人**不互相呼叫**(現況已成立);LAN 啟動器加上述防呆。
3. 網站只提供**分析**;**沒有**下單、控制機器人、讀寫機器人檔案的任何端點,**也不會新增**。
4. 網站與機器人是同一個 Windows 使用者的行程,**沒有作業系統層隔離**;所以我們靠「不提供任何檔案/路徑相關端點 + 輸入白名單 + 啟動防呆」降低風險,並在報告中明講這一點。
5. 不修改 `trading-bot/`;每個 commit 前後檢查其修改時間。
