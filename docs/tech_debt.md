# 技術債清單

## TD-1:`sim.dmi` 的 ADX 暖機種子有前視(未來修改策略引擎時再處理)
- **現象**:`sim.dmi` 的 ADX 以「第 14~27 根 DX 的平均」當種子,卻從第 15 根就開始遞迴;ADX 第 15~26 根用到了之後的 DX(輕微前視),且那幾根 DX 被重複計入。影響隨距離指數衰減:第 100 根以後差 < 0.03,第 150 根以後 < 0.001。
- **受影響**:`diadx`、`ema50_200_adx`、`adx_di`、`adx_di_trend`、`holy_grail`(用 ADX)與 `dmi_cross`(只用 ±DI,不受影響)。機器人的 `sim.py` 與本 app 逐字相同。
- **實測影響**(C1.1 第二部分,`validation/stage3_ui/C1_1_adx/warmup/warmup_study.md`):正式回測窗口(只算窗口起點之後進場的交易)、排名、OOS、機器人 `CHZ 4H ema50_200_adx` 的決策,A(現行)/B(教科書因果版)/C(嚴格暖機)**差異 0**。唯一可見:未做窗口過濾的整段統計(例如機器人首次的凱利種子,CHZ 38 筆中第一筆)。
- **決定**(使用者,C1.2 審查):`sim.dmi` 暫不修改,也不實作 `dmi_causal` 版本切換。若日後修改策略引擎,走「新增 `dmi_causal`、引擎版本參數預設 `v1`、先在研究端全量前後比對、機器人端另案批准」的版本相容方案(見 `docs/c1_1_adx_audit.md` §9)。
- **C2 的關係**:C2 的市場環境分類**不使用** `sim.dmi`,而是 `market_regime.py` 內自己的因果 Wilder ADX(逐根只用當時及過去的 K 棒)。
