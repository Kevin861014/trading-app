# C3:免費規則式研究摘要

範圍只有 C3。沒有 AI、沒有預測、不使用任何付費服務;不改策略計算、交易成本、原始回測、ADX 技術債(`sim.dmi`)、`trading-bot/`、實盤設定。摘要**不是**買賣訊號,也不會套用到機器人。

## 第一部分:兩個小修正
1. **大盤環境對齊改看「收盤時間」**(`market_regime.align_reference`、`regime_study.bar_close_ms`)。主標的這一根的決策時間 = 它的收盤時間;只能使用「收盤時間 ≤ 決策時間」的參考 K 棒。
   - 收盤時間:加密 = 開盤 + 週期;股票日線 = 當地交易日收盤(台北 13:30、紐約 16:00,夏令/冬令自動換算);股票 1H = min(開盤 + 1 小時, 當天收盤)——美股 15:30 那根 16:00 收、台股 13:00 那根 13:30 收。
   - 結論:C2 的邏輯對「同市場、同週期」本來就沒有洩漏(測試證明新舊規則在真實日線上結果逐根相同),但規則只比開盤時間,遇到不同週期會洩漏(例如日線參考對 1H 決策);現在明確改成收盤時間。測試 `tests/test_regime_alignment.py`(7 項):美股 1H/日線在冬令與夏令(2026-03-08 切換前後、11-01 回歸)的收盤、台股 1H/日線、加密;邊界(收盤時間相同可用、晚 1 毫秒不可用);日線參考不能用在同日 1H 決策(舊規則會洩漏);跨夏令時間與週末的 1H 逐根一對一;參考缺一根時退回上一根已收盤的,不用下一根。
2. **OOS 揭露紀錄不是可靠機制,畫面明說**。前端的「條件試驗紀錄」(每個標的/週期/策略/期間)列出本流程試過的每個條件(時間、環境基準、允許的環境、濾網後樣本內筆數與 PF、是否已揭露樣本外),≥ 3 個條件顯示多重比較警告,≥ 2 個條件揭露樣本外顯示「樣本外不再獨立」。紀錄只存在這個瀏覽器的 localStorage:**清除瀏覽器資料、換瀏覽器或裝置、直接呼叫 API 都會繞過它,所以不是可靠的防過度擬合機制,只是提醒你自己**;沒有帳號、沒有資料庫。摘要也會引用試驗次數(前端傳入,屬自述資料)。

## 第二部分:規則式摘要(`rule_summary.py`、`POST /api/rule_summary`)
輸入是前端已經拿到的 `/api/regime_study` 與 `/api/mtf` 回應(以及試驗次數),端點**不下載資料、不跑回測、不重算績效**(測試:下載函式被換成「呼叫就失敗」仍可運作)。輸出的每一句話都由「固定模板 + 依據欄位的數值」組成,並附 `evidence`(API 路徑、顯示值、原始值);測試逐一確認:依據欄位的值 = API 回應裡的值、顯示值 = 固定格式化規則、文字裡的每個數字都來自依據欄位或規則裡的固定門檻、沒有未填的 `{}`、沒有「建議買進/保證/預測會」等字眼。

段落:資料品質 → 目前市場環境與判斷依據(ADX/±DI/EMA/大盤)→ 各時間週期是否一致(沿用 `/api/mtf` 的彙整文字)→ 選定策略的歷史績效(整體、樣本內、樣本外)→ 目前環境下歷史交易夠不夠支持判斷 → 市場濾網對照。

### 固定規則(`rule_summary.RULES`,畫面上也可展開)
1. 環境分類同卡片:ADX (Wilder, 14) ≥ 25 且 +DI ≥ −DI 上升;≥ 25 且 +DI < −DI 下降;< 20 盤整;20–25 轉換中。
2. 資料過期、不足、時間戳異常、取得失敗(阻擋型品質)→ 只描述歷史狀態,不評估目前環境、不下結論。品質檢查沒有結果 → 視為未檢查,同樣不下結論。
3. 窗口內沒有交易 → 不評估策略、不推論。樣本內 < 20 筆 → 一律標「樣本不足」,數字只是描述。
4. 樣本外 < 5 筆證據不足;5–19 筆樣本不足(僅供參考)。
5. 樣本內與樣本外淨 PF 都 ≥ 1 才說「沒有看到樣本外失效的跡象」;樣本內 ≥ 1、樣本外 < 1 → 「樣本外沒有延續」;其他組合說明不一致或沒有正期望。
6. 目前環境的支持度:該環境樣本內 ≥ 20 筆才評論淨 PF 與樣本外;否則「樣本不足,不能判斷」;0 筆 → 「沒有證據」。
7. 濾網:濾網後樣本內 ≥ 20 筆且淨 PF 高於原始 → 「樣本內改善」;**樣本外尚未揭露時一律說「沒有樣本外證據」**(摘要不會碰到未揭露的樣本外數字,測試確認);揭露後樣本外也 ≥ 20 筆、淨 PF 高於原始且 ≥ 1 才說「方向與樣本內一致」;樣本內沒改善時不用樣本外背書。
8. 條件試驗 ≥ 3 → 多重比較提醒;樣本外揭露 ≥ 2 → 不再獨立提醒。
9. 不產生「建議買進/賣出」、價格預測或報酬保證。

標題結論只有四種:資料過期或異常 / 樣本不足或資料不足 / 沒有交易 / 描述性摘要;沒有任何「看多、看空、可以進場」類的結論。

## 第三部分:介面(沒有新增儀表板)
- **市場環境頁**:「環境 × 策略歷史績效」結果上方的「研究摘要」卡(按「產生／更新研究摘要」)。使用該面板已有的結果;多週期資料缺的話用既有的多週期流程補(有既有進度列,已快取的標示「使用快取」)。已產生過摘要後,更新濾網比較會自動重新整理摘要(不重跑分析)。
- **標的分析頁**:標的標頭下的同一張卡,用該頁的標的/策略/期間/時框向既有 API 取(走快取)後整理。
- 每句話可展開「判斷依據」(欄位路徑 + 數值),並有「查看對應數據」跳轉(市場頁捲到對應表格並短暫框線標示;標的分析頁的績效就在本頁,其他數據跳到市場環境頁)。固定規則清單可展開。
- 桌面與 iPhone 尺寸:觸控目標 ≥ 44px、無橫向溢出、最小字級 12px。

## 驗證
- 測試 288 項全過(新增:對齊 7、規則摘要 16、既有 C2 前端測試補充文字)。情境:正常(BTC/SOL)、樣本不足(SOL 日線、2330.TW、AAPL)、資料過期(資料時間往後推 12 天,真實的品質檢查判為過期)、沒有交易(BTC 4H `adx_di_trend` 近 1 年真實 0 筆)、OOS 不佳、OOS 證據不足、濾網各情境、試驗次數警告。

- `validation/stage3_ui/C3/scenarios.md|json`:各情境的真實 API 回應與摘要;`real_*.png` 桌面/手機截圖(市場頁摘要、展開判斷依據、試驗紀錄與警告、資料過期／樣本不足／沒有交易情境、標的分析頁摘要)。

## 限制
- 摘要整理的是前端傳來的回應(本機單人使用);試驗次數是前端自述。端點不驗證這些資料是真的 API 輸出——這是研究輔助,不是安全邊界。
- 規則式文字刻意保守、偏重「為什麼不能下結論」;多數標的在 2 年窗口內樣本不足,所以多數摘要會是「樣本不足」類。
- 沒有真實 iPhone 測試。
