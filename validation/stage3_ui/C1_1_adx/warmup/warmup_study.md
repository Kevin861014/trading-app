## 2. 歷史資料起始日期是否影響正式回測窗口內的訊號

做法:把資料最前面砍掉 k 根(窗口內資料不動),比較窗口內(最近 730 天)的進出場訊號與完整回測交易。6 條序列 × 6 策略 = 36 組。

| 版本 | 砍掉前 k 根 | 窗口內訊號有變的組數 | 窗口內進場日不同的組數 | PF 不同的組數 |

| A | 50 | 0 / 36 | 0 | 0 |
| A | 200 | 0 / 36 | 0 | 0 |
| A | 400 | 3 / 36 | 3 | 1 |
| B | 50 | 0 / 36 | 0 | 0 |
| B | 200 | 0 / 36 | 0 | 0 |
| B | 400 | 3 / 36 | 3 | 1 |
| C100 | 50 | 0 / 36 | 0 | 0 |
| C100 | 200 | 0 / 36 | 0 | 0 |
| C100 | 400 | 14 / 36 | 6 | 4 |

砍掉 400 根時 A 與 B **同樣**只有 3 組有變(2330.TW ema50_200_adx、AAPL ema50_200_adx、NVDA ema50_200_adx),這幾組都是 `ema50_200_adx`:是 EMA200 還沒收斂(日線資料只剩約 45 根窗口前暖機),**不是 ADX**。C100 在這個極端下多出變動,是因為窗口前只剩 45 根、卻要求遮蔽 100 根,把窗口內的前面幾根也遮掉了:**嚴格暖機長度 K 不能大於窗口之前實際可用的歷史**。
